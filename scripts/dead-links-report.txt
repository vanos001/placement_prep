DEAD EXTERNAL LINK BACKLOG
==============================================================================

Audit trail for the external-URL pass. Internal links, anchors, SUMMARY,
Mermaid, MathJax, fences and all DOIs are clean and checked by
scripts/validate-all.sh; THIS file tracks third-party URLs only.

The catalogue below comes from a FULL-REPO sweep (2026-09-19, second pass):
every distinct external URL in src/ was fetched, not just the ones flagged
earlier. That is why the totals differ from the first catalogue.

WHAT THE FULL SWEEP FOUND
------------------------------------------------------------------------------
  external URLs swept (distinct hosts: 2067) : 8662
  HTTP 200 (live)                              : 5872
  HTTP 404 / 410 (dead)                        : 761
  HTTP 403 (blocked to scripted clients)       : 645
  HTTP 429 (rate-limited during the sweep)     : 669
  bot challenge / other non-200                : 715

  Only 404/410 is a reliable 'gone' signal. 403/429/challenge responses are
  almost certainly live pages refusing this client; they are NOT counted dead.
