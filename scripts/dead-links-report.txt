Why this file exists: the repo's README badge and meta/* pages claimed
"0 broken links", but scripts/check-links.py only validated INTERNAL
links unless EXTERNAL=1 was passed, and no workflow ever passed it. A
full probe of all 6,458 external URLs found 758 dead ones (647 x HTTP 404).

The internal-link, anchor, SUMMARY, Mermaid, MathJax and fence checks all
pass on the fixed tree; this file tracks the remaining external-URL work,
which needs human judgement (many are moved docs pages, not typos).

Most common cause: docs.kernel.org deep links. Kernel documentation does
not mount pages at the repo-root path, e.g.
