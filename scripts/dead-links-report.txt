DEAD EXTERNAL LINK BACKLOG
==============================================================================

Audit trail for the external-URL pass. Internal links, anchors, SUMMARY,
Mermaid, MathJax, fences and all DOIs are clean and checked by
scripts/validate-all.sh; THIS file tracks third-party URLs only.

Original probe (2026-09-19, before this pass): 6,458 external URLs,
758 reported dead. A careful re-probe showed that number was partly noise:
20 of the 758 were transient failures (DNS/SSL/timeout) and resolve fine.

------------------------------------------------------------------------------
WHERE THE 758 WENT
------------------------------------------------------------------------------
  fixed with a verified LIVE replacement : 129
      - kernel.org / docs.kernel.org     : 93
      - man7.org (man pages)             : 20
      - URL variant (slash/www/index)    : 16
  fixed with an ARCHIVED snapshot       : 32
  false positives (resolve fine now)    : 20
  blocked by bot protection (403/wall)  : 30
  unverifiable (connection error)       : 76
  still dead (hard 404)                 : 471
                                          -----
  total                                 : 758

------------------------------------------------------------------------------
WHAT WAS FIXED
------------------------------------------------------------------------------

1. docs.kernel.org / www.kernel.org  (93 links across 84 files)
   The single largest cluster. Most were fabricated paths, e.g.
   /security/IMA.html, /networking/qdisc.html, /mm/slub.html -- none of
   those documents exist at those paths. Each was re-pointed using
   docs.kernel.org's own searchindex (4,074 real document paths), then
   verified by fetching the target and checking its <title>, e.g.
     www.kernel.org/doc/Documentation/block/blk-mq.txt -> docs.kernel.org/block/blk-mq.html
     docs.kernel.org/security/tomoyo.html              -> docs.kernel.org/admin-guide/LSM/tomoyo.html
     docs.kernel.org/virt/kvm/mmu.html                 -> docs.kernel.org/virt/kvm/x86/mmu.html
   Where no page exists for a topic, the link now points at that
   section's index (e.g. /networking/index.html) rather than a 404.
   git.kernel.org was NOT used as a replacement: it sits behind an
   Anubis anti-bot wall that answers bots with HTTP 200 + a challenge
   page, so targets there cannot be verified and were avoided.

2. man7.org  (20 links across 16 files)
   man7.org 404s for man pages it does not mirror (apt, chroot, nmcli,
   nft, qemu-img, watchdog, ...). Re-pointed to manpages.debian.org,
   whose /<name>.<section> URLs are version-agnostic and stable.

3. URL variants  (16 links)
   Trailing-slash, www-vs-bare, and .html/index.html normalisations.
   Every candidate was re-checked for soft-404s: e.g. an NVIDIA PDF
   'fixed' by adding a slash returned HTTP 200 with the title
   'Page Not Found', and a Merkle/NRC 'fix' silently redirected to the
   site homepage. Those candidates were rejected (topic-token check).

4. Archived snapshots  (32 links)
   For hard 404s with no live equivalent, links now point at
   web.archive.org snapshots. All 32 were fetched and confirmed live.
   These are the only non-primary sources in the book.
