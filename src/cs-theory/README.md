## Why CS Theory Matters

- Tests fundamental reasoning ability
- Required for algorithm correctness proofs
- P vs NP appears in interviews as a discussion topic
- Proof techniques help in algorithm design
- Sets/relations/logic form the basis of databases, type systems, and formal methods
