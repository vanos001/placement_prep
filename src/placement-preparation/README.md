## Campus Placement Timeline

```
Resume Screening → Online Assessment → Technical Interview(s) → Managerial Interview → HR Interview → Offer
     (1 week)        (1-2 hours)         (1-3 rounds)            (0-1 round)          (1 round)
```

## Key Preparation Areas

1. **DSA**: 200-300 problems on LeetCode/GFG (medium difficulty)
2. **CS Fundamentals**: OS, DBMS, Networks, OOP
3. **Projects**: Be able to explain architecture, decisions, trade-offs
4. **Resume**: Tailored, quantified, ATS-friendly
5. **Communication**: Think aloud, ask questions, be concise
6. **Aptitude**: Quantitative, logical reasoning (for OAs)
7. **Behavioral**: STAR method for HR questions
