# Bluetooth

## Overview

Bluetooth is a short-range wireless technology for PANs (Personal Area Networks), operating in 2.4 GHz ISM band. Used for audio, HID, IoT.

## Core Concepts

- **Profiles**: A2DP (audio), HID (keyboards), BLE GATT (IoT)
- **Versions**: Classic (BR/EDR) vs BLE (Bluetooth Low Energy)
- **Stack**: PHY -> Link Layer -> L2CAP -> ATT/GATT
