## Why Math Matters for Programming

- Algorithm analysis (complexity, correctness proofs)
- Cryptography (modular arithmetic, primes, RSA)
- Probability (randomized algorithms, hashing, load balancing)
- Linear algebra (ML, graphics, optimization)
- Graph theory (networks, scheduling, pathfinding)
- Combinatorics (counting, DP state spaces)
