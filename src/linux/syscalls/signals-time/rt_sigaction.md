## Purpose

rt_sigaction() installs or queries the disposition of one signal: what happens when that signal is delivered (default action, ignore, or a handler). It is the rt_* form of the original sigaction() syscall, added in Linux 2.2 because the fixed-size 32-bit sigset_t of the old call could not express the real-time signal range (sigaction.2, C library/kernel differences).

## Synopsis

```c
#include <signal.h>
int sigaction(int signum, const struct sigaction *act,
              struct sigaction *oldact);
/* kernel ABI */
int rt_sigaction(int signum, const struct kernel_sigaction *act,
                 struct kernel_sigaction *oldact, size_t sigsetsize);
```

## Arguments and behavior

signum is the signal number (from <signal.h>; SIGKILL and SIGSTOP cannot be changed). If act is non-NULL the new action is installed; if oldact is non-NULL the previous action is saved; both may be NULL (sigaction.2). The struct sigaction in user space (glibc bits/sigaction.h) holds a handler union (sa_handler, or sa_sigaction with SA_SIGINFO), sa_mask (blocked during handler execution, in addition to the triggering signal unless SA_NODEFER), sa_flags, and sa_restorer (not for application use). The kernel call takes a fourth argument sigsetsize, currently required to equal sizeof(sigset_t) or EINVAL results (sigaction.2).

## Return value and errors

0 on success; -1 with errno on error. Errors (sigaction.2): EFAULT (act or oldact points outside the address space); EINVAL (invalid signal, or attempt to change SIGKILL/SIGSTOP, or wrong sigsetsize on the kernel call).

## Security and notes

Dispositions of handled signals reset to default across execve(); ignored dispositions persist; fork() inherits dispositions (sigaction.2 NOTES). POSIX leaves behavior undefined after ignoring SIGFPE/SIGILL/SIGSEGV not generated by kill(2)/raise(3). Attempts to block SIGKILL/SIGSTOP in sa_mask are silently ignored.
