## Key Concepts

- **Inverted Index**: Maps terms to documents (like a book index)
- **Tokenization**: Splitting text into terms
- **Stemming/Lemmatization**: Reducing words to root form
- **TF-IDF**: Term frequency × inverse document frequency
- **BM25**: Improved TF-IDF used by Elasticsearch/Lucene
- **Relevance Scoring**: How well a document matches a query
