## Why Frontend Matters for Placement

Even backend/fullstack roles expect frontend literacy:
- Understanding the request lifecycle (browser → server → render)
- Knowledge of JavaScript event loop affects backend Node.js
- React/component model patterns influence modern UI frameworks
- CSS/layout knowledge needed for any web-facing role
