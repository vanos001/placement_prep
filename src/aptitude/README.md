## How to Use This Section

1. **Start with fundamentals** — Percentages, Ratios, Averages form the base for everything else.
2. **Practice shortcuts** — Each topic includes time-saving tricks critical for timed tests.
3. **Solve practice questions** — Every file has worked examples and practice problems with solutions.
4. **Mix topics** — Real exams combine topics; practice mixed problem sets.

## Tips for Speed

- **Memorize** multiplication tables up to 30, squares up to 40, cubes up to 20
- **Learn** fraction-percentage equivalents (1/8 = 12.5%, 1/6 = 16.67%, etc.)
- **Practice** mental math daily — even 15 minutes helps
- **Time yourself** — aim for 30-45 seconds per question in practice
