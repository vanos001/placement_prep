# Resume Tailoring Per Role

A generic resume submitted to ten different roles will underperform a tailored version for each. Tailoring means reordering, rewording, and reemphasizing content to match what each specific role demands.

## Why Tailoring Works

| Approach | Keyword Match | Interview Callback Rate |
|----------|--------------|------------------------|
| Generic resume | 30-40% | Low |
| Lightly tailored | 50-65% | Moderate |
| Fully tailored | 70-90% | High |

Recruiters and ATS both look for alignment between the job description and your resume. The closer the match, the higher you rank.

## The Tailoring Process

### Step 1: Parse the Job Description

Extract three categories from the posting:

```
MUST-HAVE (required skills — include all that you have):
- Python, PostgreSQL, REST APIs, Git

NICE-TO-HAVE (preferred — include if applicable):
- Kubernetes, CI/CD, microservices

ACTION VERBS (mirror their language):
- "Architect," "Optimize," "Scale," "Automate"
```

### Step 2: Reorder Your Skills Section

Put the most relevant skills first. If the job emphasizes cloud, list AWS/GCP/Azure before your other tools.

### Step 3: Rewrite Bullet Points for Relevance

**Before (generic):**
> Developed a web application using Python and JavaScript.

**After (tailored for backend role):**
> Built a REST API in Python serving 10K daily requests with PostgreSQL backend and Redis caching, reducing response time by 60%.

**After (tailored for full-stack role):**
> Developed a full-stack web application with React frontend and Python/Flask backend, implementing responsive design and reducing page load time by 40%.

### Step 4: Quantify Impact

| Weak | Strong |
|------|--------|
| Improved performance | Reduced API latency from 2s to 200ms (90% improvement) |
| Built a feature | Shipped search feature used by 5K daily active users |
| Led a team | Led 4 developers to deliver a project 2 weeks ahead of schedule |

### Step 5: Select Relevant Projects

If you have more projects than space allows, choose those closest to the target role. A data engineering applicant should feature an ETL pipeline, not a mobile app.

## Role-Specific Tailoring

| Target Role | Emphasize | De-emphasize |
|-------------|-----------|--------------|
| Backend Engineer | APIs, databases, distributed systems | CSS, UI libraries |
| Frontend Engineer | React/Vue, responsive design, accessibility | Backend infrastructure, DevOps |
| Data Engineer | ETL, SQL, Spark, data pipelines | Frontend frameworks, mobile dev |
| DevOps/SRE | CI/CD, monitoring, cloud, containers | Business logic, UI work |
| ML Engineer | Python, TensorFlow/PyTorch, model deployment | Web development, manual testing |

## Common Mistakes

- **Keyword stuffing:** Repeating the same keyword 10 times looks unnatural and ATS may penalize it.
- **Lying:** Only list skills you can demonstrate in an interview.
- **Ignoring soft skills:** Communication, leadership, and collaboration are often in the job description.
- **One-size-fits-all file name:** Use `FirstName_LastName_Role_Company.pdf`.

## Quick Tailoring Checklist

- [ ] Identify 10-15 keywords from the job description
- [ ] Verify each keyword appears at least once in your resume
- [ ] Reorder skills section by relevance
- [ ] Adjust 2-3 bullet points per role
- [ ] Select the 2-3 most relevant projects
- [ ] Update file name for the specific application
